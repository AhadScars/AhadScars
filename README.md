### [Secure Banking API](https://github.com/AhadScars/Secure-Banking-REST-API-Spring-Boot-JWT)

Savings and current accounts. Deposit, withdraw, transfer, balance, and history.

- JWT and RBAC for `ADMIN` and `CUSTOMER`, with ownership checks
- Unique 10-digit account numbers and `TXN` references
- Active-account and sufficient-balance checks before money moves
- A transfer writes both ledger lines in one `@Transactional`
- **MySQL** · Java 17 · Spring Data JPA · port `8081`
